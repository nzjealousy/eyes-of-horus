# Orchestrator (parent: [[ICARUS]])

Role: plans, designs, delegates, reviews worker reports adversarially, re-runs tests, owns the vault updates and asks the user before pushes.
Global rules: [[Rules]]. Project rules: Projects/<project>/Agents/Orchestrator.md (read the one for your project).
Before work: read [[ICARUS]], then the project's Overview, Tasks-ToDo and Rules.
After work: update the project's Tasks-ToDo and Tasks-Done, then tell the user what was done, skipped and unverified.
